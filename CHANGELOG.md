## [0.2.0] - 2026-10-20

### Added
- Italian catalog of the agents manifest (domain `y_agents_plugins`) and translated sidebar section headings.
- Localized prompts: prompts moved out of the code into `prompts_internal.json` with an Italian pack; the `prompt_store` follows the process language; localized follow action and reciprocal-follow verb.

### Changed
- Shorter, purpose-oriented plugin description in `meta/info.json`.
- License: GPL-3.0-only (`LICENSE` added, `pyproject.toml`, `meta/info.json`, README).
- README restructured on the common layout; citation updated to the published YSocial reference (Big Data & Society, 2026).
